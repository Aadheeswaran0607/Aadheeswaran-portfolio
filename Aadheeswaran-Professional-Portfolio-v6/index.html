06 / Case Study

How I approached SafeWalk.

01

Problem

In an emergency, users may need to reach trusted contacts and communicate their situation without moving between several disconnected tools.

02

Solution

Bring key safety actions into one application: contacts, SOS, location sharing and WhatsApp emergency communication.

03

Engineering

Connect a browser UI to Spring Boot REST endpoints, persist application data through JPA/Hibernate and MySQL, then validate the flow end to end.

04

Challenge

The main challenge was making frontend, backend, database, location and communication flows work together reliably across local development and deployment.

05

Debugging

I worked through API integration, database connectivity, configuration and deployment issues by tracing behaviour layer by layer and testing the complete flow.

06

Outcome

A working full-stack application with persistent storage, emergency workflows and a live cloud deployment that can be demonstrated to recruiters.
